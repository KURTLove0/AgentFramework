# 变更评估 Skill · 1.0.0

适用：test 环境内，评估一个指定变更并创建供人工审核的草稿。

1. 读取变更、服务、依赖、测试结果和回滚方案，保存来源、版本、时间及内容摘要。
2. 检索 release-review-rubric@1.0.0；缺少关键证据时请求补充，不编造事实。
3. 失败测试大于零判 HIGH，否则存在依赖判 MEDIUM，否则判 LOW。
4. 报告包含 summary、impact、risks、test_results、rollback、recommendation；关键事实引用证据。
5. 本地验收通过后才可提出创建草稿，网关仍需检查实际授权和资源版本。
6. 创建后独立回读，比较对象、状态、版本、内容与哈希。
7. 写入响应不明时按运行时生成的幂等键核对。仅在权威查询确认未发生后才可重试；无法判断则转人工核对。
8. 经验只形成 PENDING_REVIEW 候选，不在线修改 Skill、授权或验收规则。

本方法文字不能授予工具权限。模拟规划器通过同版本 manifest 执行结构化规则；替换真实模型后仍受相同网关与验收器约束。
