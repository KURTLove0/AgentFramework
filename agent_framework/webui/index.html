新建任务

写下目标，交给合适的智能体执行。

可以补充背景、要求和交付形式。

↑ ↓ 选择 ↵ 打开 · Esc 关闭

从一个任务开始

  1. 准备工作空间

    按业务或场景创建空间，分别保存智能体、任务和资料。

    管理工作空间 →
  2. 创建你的智能体

    填写名称，选择模型并设定工作指令；处理领域与技能可按需配置。

    创建智能体 →
  3. 交办一个任务

    点击“开始使用”，填写目标并选择执行智能体。失败或中断后可从原记录继续。

  4. 查看结果并改进

    实时查看公开摘要与回答，直接在原任务追问或修改；完成后可复盘、沉淀资料。

    配置每日任务 →
本地运行说明

业务工具使用模拟实现。真实模型模式会使用所选模型服务及其登录态；开始任务后使用智能体的执行配置；具体写入在执行时授权。

服务仅监听本机。停止后使用相同数据目录重新启动，即可继续查看或恢复任务。

sh scripts/start.sh

AGENT DEFINITION

创建智能体

绑定运行时与 CLI 模型，为后续任务保存可复用的 Agent 配置。

此智能体沿用历史执行配置，可继续使用。切换为通用配置后，可按工作指令处理不同任务。

Prompt 与启用的 Skill 将进入规划上下文；任务范围、业务授权和验收规则仍独立生效。

角色与业务领域

管理领域

选择已有领域，或创建适合业务的新领域。

新建处理领域

自由描述处理方法与输出要求。新领域可被多个智能体复用，执行模板单独配置。

职责与交付物

按需细化职责、交付内容和结果检查要求。普通任务会按实际目标执行。

执行标准

选择已登记的版本化标准；运行时独立执行检查，Prompt 无法覆盖这些标准。

能力绑定与编译预览

工具能力由智能体的执行配置决定。处理领域只提供业务背景与工作方式；选择读取能力后，任务按需使用。

Skills

从当前空间的已发布 Skill 中选择并固定版本。名称和描述先进入目录，正文与资源按需加载。管理 Skill 标准包

MCP 服务

已保存的连接配置保留供迁移。新任务可在“模型原生只读 MCP”中选择已登记的读取能力。
