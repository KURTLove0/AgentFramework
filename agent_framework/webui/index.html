从一个任务开始

  1. 准备工作空间

    按业务或场景创建空间，分别保存智能体、任务和资料。

    管理工作空间 →
  2. 创建你的智能体

    选择用途、填写名称并设定工作指令。可以先用模拟模式体验，再连接本机模型。

    创建智能体 →
  3. 交办一个任务

    点击“开始使用”，填写目标并审查本次配置和权限。失败或中断后可从原记录继续。

  4. 查看结果并改进

    阅读报告与来源，检查验收结果；可复盘沉淀经验，或配置每日任务与岗位评测。

    配置每日任务 →

AGENT DEFINITION

创建 Agent

绑定运行时与 CLI 模型，为后续任务保存可复用的 Agent 配置。

Prompt 与启用的 Skill 将进入规划上下文；任务范围、业务授权和验收规则仍独立生效。

角色与业务领域

选择已有领域，或创建适合业务的新领域。

新建处理领域

工作方式决定可用工具和验收流程。新领域会保存在当前空间，供其他智能体复用。

职责与交付物

每项职责绑定交付物与验收项，所有必选验收必须有职责负责。

执行标准

选择已登记的版本化标准；运行时独立执行检查，Prompt 无法覆盖这些标准。

能力绑定与编译预览

能力由处理领域的方法决定。原生 MCP 仅可选择已登记的只读能力；编译通过后仍需取得任务写权限。

Skills

从当前空间的已发布 Skill 中选择并固定版本。名称和描述先进入目录，正文与资源按需加载。管理 Skill 标准包

MCP 服务

历史端点配置保留供迁移。启用未登记效果的直连会阻止编译；新任务请在岗位定义的 native_read_refs 中选择受控读取能力。
