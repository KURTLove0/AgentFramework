- 重试成功后进入归档状态并去除任务入口。

## 新发现且尚未关闭

**PM-03，P1：较早发起的自动刷新能覆盖较新的操作回执。**

专项顺序：开始 GET 并保存归档 v4 列表快照，延迟该 GET；点击恢复，POST 成功返回可用 v5；释放旧 GET。最终页面退回已归档 v4，再次展示“恢复使用”。证据在 `round-1-race-audit-results.json` 最后一项及 `screenshots/round-1-race-stale-list.png`。

`refresh()` 直接采纳列表结果，尚未辨别请求发出后已经完成的保存或归档。需要丢弃旧列表快照或确保记录不回退版本，并分别复验旧 GET 晚于归档和晚于恢复两种方向。
