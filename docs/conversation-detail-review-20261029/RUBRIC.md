# 对话界面细节评分标准

本标准在本轮修改前固定，评审对象为任务持续对话与工作流设计对话。当前产品范围是桌面 Web/PC，覆盖浅深主题、1024/1280/1440/1920px、720px 短窗口和 200% 文字。

每项 0–5 分：5 = 一致且已有直接证据；4 = 有非阻断的局部不足；3 = 存在明显不一致或验证不足；2 = 阅读或操作受影响；1 = 严重影响；0 = 缺失。每一分保留具体依据；自动测试不直接产生视觉分数。遮挡、不可操作、数据丢失等阻断问题不能被平均分掩盖。

| 维度 | 分值 | 每项 5 分的检查内容 |
| --- | ---: | --- |
| 字号与层级 | 25 | 正文/输入/发送按钮遵循统一字号；辅助说明可读；标题与正文区分；正文行高适中；代码、链接和长文本可读 |
| 消息布局 | 25 | 角色与左右关系清晰；阅读宽度合理；姓名和过程信息不过度抢占；丰富内容与长消息不溢出；长对话保留历史阅读位置 |
| 输入区 | 25 | 两种对话尺寸与内边距一致；标签和输入文字左边缘误差不超过 2px；聚焦与错误不改变几何；长输入有边界且可编辑；主要发送操作清楚且可达 |
| 交互状态 | 15 | 发送中/失败/重试反馈；中文输入/草稿/光标与排队；键盘操作及当前执行者与提案操作可识别 |
| 桌面适配 | 10 | 常规宽度与短窗口无遮挡，长提案操作可达；200% 文字下输入与主要操作可用 |

视觉判断结合截图和真实浏览器测量。模型调用使用隔离的模拟响应，不以此宣称完成真实用户研究、全浏览器或实体输入法认证。
