# 状态变化后的阅读恢复

2026-11-04。源码改进，版本保持 1.3.0，尚未发布。

流式追加已能保留未变化节点，但任务完成、状态变化或本页重新读取仍可能重绘整段对话。此前普通文字选区会被清空，使用键盘查看的来源链接也会失焦。现在重绘前保存当前阅读位置描述，在新页面中核对后恢复。

## 使用体验

- 普通段落、强调文字、列表和表格中的选区可跨整页重绘保留，包含反向选择、跨段及跨轮次选择。
- 生成片段被最终结果替换时，原选中内容及其定位仍一致，就继续保留选区；不要求整个回复完全相同。
- 来源链接的地址与文字未变时恢复键盘焦点，不主动打开链接。
- 用户转去输入框、选择框或可编辑区域后，保留新的输入焦点和选区。
- 所选内容已改写、定位结构不再对应、任务或轮次身份改变时放弃恢复，不选择另一段相似文字代替。

这是当前页面重绘的恢复，不把选区写入浏览器存储，也不承诺浏览器重新加载、关闭后重开或离开任务后仍保留文字选区。被删除或转换结构的内容可能无法恢复；已有代码复制、横向阅读位置和流式就地更新继续使用原有机制。

## 核对方式

一次快照仅包含当前选区的两个端点、消息轮次与运行编号、正文中的节点路径和端点前文字，以及实际所选全文。元素边界端点也可记录。重绘后核对当前租户、工作空间、主体、任务与路由，再验证轮次身份、节点类型、端点文字和完整选中文字，最后按原锚点与焦点顺序恢复，因此反向选择不会变成正向。

链接焦点独立核对原地址与标签，只在原控件已被移除、当前没有其他焦点控件时恢复。快照不持有旧 DOM 节点，恢复尝试后立即清除；离开页面也会清除。没有选区时不会保存其他回复正文，流式更新不会额外扫描这些端点。

## 验证

新增 **17 项真实浏览器 DOM 检查**。原脚本上 9 项失败、8 项通过，修改后全部通过，覆盖：

- 正向、反向、跨段、跨轮、元素边界、嵌套列表和表格选区。
- 最终正文在选区之后追加内容，选区仍保留。
- 端点或中间所选正文变化时拒绝恢复。
- 任务、路由、主体、工作空间及运行编号变化时拒绝旧快照。
- 等价来源链接恢复焦点，地址改变则不恢复。
- 输入焦点及后来选区优先，空选区不复活，恢复只能消费一次，快照不保留旧节点。
