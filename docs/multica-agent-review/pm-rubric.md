# 产品经理 Agent：智能体 UI 与动线固定量表

评审目标：参考 https://multica.ai/kl/agents 的可扫描目录、筛选排序、详情与配置分层，改进现有 Agent Framework。总分达到 95/100 且不存在阻断问题后停止。量表在实现前固定；不通过删减标准取得目标分数。

评审角色：独立产品经理 Agent。主 Agent 负责实现，产品经理负责检查证据并给出逐项评分。本评分衡量本次实现的可用性与验收覆盖，不等同于真实用户满意度、竞品优劣或平台认证。

## 计分与停止规则

每项 4 分，共 25 项。4=满足且有对应的源码、实测或截图证据；3=主要满足，有明确的非关键欠缺或证据边界；2=部分满足，仍有明显使用成本；1=仅有雏形；0=缺失或不可用。视觉判断须看实际截图，交互判断须有实际操作或回归证据；源码初评不得冒充实测。历史报告只证明历史版本，不能替代当前改版复验。

以下任一问题存在，不得宣布达到 95：无法从目录选定 Agent 并开始任务；详情身份/任务身份不一致；创建或编辑丢失已填内容；归档误执行任务；跨空间显示或使用错误 Agent；主要动作在小屏/键盘下不可达；权限或业务授权被自动继承；明显错误、空白页或无法返回目录。未验证的核心动线同样不能视为通过。

达到目标需同时满足：总分 >=95；所有阻断项关闭；新目录与详情有当前版本浏览器证据；320/375/414/768/1440、浅/深色以及代表性长文本有证据；原创建和任务闭环回归通过。每轮报告记录未满足项和具体改进，量表保持不变。

## 固定 25 项

| ID | 维度 | 4 分验收标准 |
| --- | --- | --- |
| V1 | 视觉与层级 | 标题、总量、主要创建操作明确，页面使用现有设计系统，主次动作可辨。 |
| V2 | 视觉与层级 | 目录采用紧凑可比较的项目结构；先看到名称、用途、状态和必要元数据，长职责/指令不挤占目录。 |
| V3 | 视觉与层级 | 详情按内容任务分层，有清晰身份摘要与持续可发现的开始任务/编辑入口，技术内容按需展开。 |
| V4 | 视觉与层级 | 计数、版本、技能、状态均来自真实记录；可用、归档和模拟运行不被表达成未经验证的在线/质量数据。 |
| V5 | 视觉与层级 | 实际浅/深截图字体、间距、边界与动作对齐一致，长名称保持可识别，空状态与有内容状态均完整。 |
| F1 | 查找和选择 | 按名称、岗位、团队、模型等已支持真实字段搜索，输入焦点稳定，中文输入法不被刷新打断。 |
| F2 | 查找和选择 | 全部/可用/归档与领域筛选语义明确，计数和结果一致，归档记录有明确恢复入口。 |
| F3 | 查找和选择 | 目录有可理解的排序方式、当前排序提示和确定性结果；操作后不会意外改变筛选上下文。 |
| F4 | 查找和选择 | 首次空白与筛选无结果有不同提示及有效下一步，已应用筛选可显式清除。 |
| F5 | 查找和选择 | 进入详情再返回时保留搜索、筛选和排序，列表选择上下文可恢复，刷新不会抢走正在输入的内容。 |
| D1 | 详情到执行 | 名称/目录项目可进入独立可链接的 Agent 详情，刷新或直接打开仍显示正确身份。 |
| D2 | 详情到执行 | 用户可以从详情阅读职责、标准、工作指令、固定技能及实际模型配置，信息与保存记录一致。 |
| D3 | 详情到执行 | 目录或详情开始任务准确预选该 Agent 与版本，明确目标输入、执行方式及任务授权审查。 |
| D4 | 详情到执行 | 从详情可到达相关运行或评测；有/无历史都合理展示，不伪造活动或统计。 |
| D5 | 详情到执行 | 目录/详情/编辑/任务之间返回可预测，浏览器前后退和不存在记录有恢复动作，空间边界正确。 |
| C1 | 创建编辑反馈 | 创建从清楚的用途起点开始，字段有标签与必要帮助，可选项按需展开。 |
| C2 | 创建编辑反馈 | 三步配置可前后移动并保留输入，确认页展示准确名称、领域、模型、职责和指令摘要。 |
| C3 | 创建编辑反馈 | 校验定位字段并保留输入，保存有等待与防重入，修正后错误正确消失。 |
| C4 | 创建编辑反馈 | 保存失败可原样重试，未保存关闭有保护；保存成功但列表刷新失败时保留权威成功回执。 |
| C5 | 创建编辑反馈 | 保存后给出持久下一步，编辑生成正确版本；任务往返保留目标和预算，并重新审查授权。 |
| A1 | 响应式与可访问性 | 目录、详情、页签/菜单及主要创建/使用动线键盘可达，焦点可见，Escape与关闭后焦点合理。 |
| A2 | 响应式与可访问性 | 320/375/414/768/1440 及代表性低高度下无页面横向溢出，核心信息/操作可达。 |
| A3 | 响应式与可访问性 | 浅/深主题的代表性正文与辅助文字对比 >=4.5:1，必要边界/焦点 >=3:1，状态不只靠颜色。 |
| A4 | 响应式与可访问性 | 主要触控操作 >=44px，长中文/标识可读，200%文字下仍可到达内容和操作，减少动态效果受支持。 |
| A5 | 响应式与可访问性 | 控件有准确名称，标题/链接/页签语义匹配行为，选中状态、结果数和错误有合适的可访问表达。 |

## 参考实现边界

参考页面以浏览器实际可见内容为优先。本地 Multica 源码可用于理解结构，但不代表当前 multica.ai 部署与本地完全相同。参考来源是 `packages/views/agents/components/agents-page.tsx`、`agent-list-toolbar.tsx`、`agent-detail-page.tsx`、`agent-overview-pane.tsx`。其中 mine/all/archived、runtime、owner、presence、run count 等建立在 Multica 数据模型上；本项目仅应采用已存在的真实数据语义。
