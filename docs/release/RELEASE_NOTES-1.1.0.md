# Agent Framework 1.1.0

2026-10-23，在 1.0.0 基础上更新工作台界面与交互，保留已有任务恢复兼容性。

- 统一九个模块的系统字体、语义配色、浅色/深色/跟随系统外观及分组导航。
- 适配桌面与手机界面；增加可见键盘焦点、移动导航抽屉和表单分段编辑。
- Agent、工作空间、知识、Skill 与工作流表单增加未保存提示、字段错误定位和提交状态反馈。
- 工作流画布与对话提案、任务授权与验收结果使用更清晰的操作和状态提示。
- 服务重启后，只在明确返回页面会话失效时刷新会话并重试一次；超时或响应未知的写入不自动重放。
- 构建使用独立源码快照，并逐文件验证 wheel 内代码与资源，防止发布旧界面或遗漏新增资源。

已有功能：

- 岗位 Agent：身份、职责、交付标准、能力约束、固定版本 Skill 选择。
- 标准 Skills：SKILL.md/资源文件、ZIP 导入导出、不可变版本、发布与撤回、按需加载。
- 工作空间与资料：创建/编辑/删除恢复，知识、记忆、经验和能力管理。
- Agent 工作流：可视化画布、分支/汇合、RAG 检索参数，对话生成可审查提案。
- 执行治理：具体参数授权、独立验收、未知写入核对、进程重启恢复和幂等控制。
- Codex/Cursor CLI 结构化规划，可选离线规划；已有任务冻结契约保持恢复兼容。

本版本清除了开发工作台的历史测试数据；完整数据备份留在开发机 `.backups/`，不进入发行包。新安装不附带测试任务、草稿、自定义岗位或演示工作流。系统内置能力、领域标准和两个标准 Skill 保留。

发布范围：单用户、本机回环访问；模拟业务工具。此版本号不代表已连接真实业务系统或已具备公网多人服务能力。服务器部署需另行提供目标位置并完成部署验证。
