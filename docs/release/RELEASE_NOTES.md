# Agent Framework 1.3.0

2026-10-27，包含当前普通任务、持续对话、流式输出、每日任务、工作流、岗位检查和本体功能，以及本轮可靠性修复。

- 本体检索固定来源版本；短标签可精确匹配；同名来源离线生成可区分名称。
- 概念检索、对象查询和动作核对统一检查有效期、来源、哈希和生效版本。撤回新版后不自动恢复旧版；可明确启用有效的已发布版本。
- 失败的结构化本体生成可创建独立修复草稿，保留原失败记录；重复请求复用同一草稿，修复后仍需通过全部约束才能沉淀。
- 断言证据支持逐字原文片段、来源哈希、字符位置、人工核对与并发版本检查，并随 JSON-LD 导出；核对状态不会自动证明业务断言正确。
- 普通离线演示不计分；普通模型任务标为结构检查分，目标达成质量待人工或专项验收。旧评分原始记录保留，展示口径兼容修正。
- 本体列表直接解释过期和未生效原因，失效版本不再提供业务对象浏览入口。
- 浏览器测试提供固定版本的 Playwright 开发依赖和统一临时服务入口；发行检查验证全部模块导入、资源加载及干净工作台启动。

发布范围仍为单用户、本机回环、模拟业务工具与 test 环境。未包含真实业务写连接器、多人身份认证或完整 OWL/SHACL 执行引擎。大规模实例存储与持续高并发部署需要另行设计和压测。

## Agent Framework 1.2.0

2026-10-23，在 1.1.0 基础上完善任务、Agent、资料和工作流之间的交互动线。原 1.1.0 安装包保持不变。

- 任务创建分为目标、执行配置、确认授权三步，最终汇总岗位版本、范围和预算。写入授权默认不勾选；配置往返保留任务草稿，修改任务范围后重新确认授权和上下文许可。
- Agent 配置提供逐步校验与最终审阅，可带入所选岗位新建任务；前往 Skills 管理后可返回未保存的岗位并选择已发布的固定版本。
- 资料保存后定位对应模块，提供下一步审核或发布入口；新建工作空间后显式进入，切换失败保留原上下文。
- 工作流画布支持节点拖动、键盘移动、平移、缩放、定位和自动整理；手机可切换画布与属性，提供点击移动节点的操作。画布位置只保存在当前浏览器，不改变工作流执行契约。
- 页面切换、提交和保存提供状态反馈，支持减少动态效果；路由恢复滚动位置，轮询不反复播放动画。未知写入不自动重放，保存回执成功后列表刷新失败不会再次创建。
- 发布构建显式包含新增交互资源，安装包只收录两个安装/启动脚本，并拒绝覆盖同版本产物。

保留：标准 Skills 与固定版本绑定、四模块知识库、工作空间管理、Agent 节点与 RAG 检索/分支工作流、Codex/Cursor CLI 结构化规划、具体参数授权、独立验收、未知写入核对及旧任务恢复。

本版本清除了运行环境的测试模拟记录，清理前完整备份留在开发机 `.backups/`，不进入发行包。首次启动只有默认工作空间与两个系统 Skill，没有测试任务、草稿、自定义 Agent、工作流、知识、记忆或经验。测试源码和历史验收资料继续保留在源码仓库。

发布范围：单用户、本机回环访问。**业务工具仍为模拟实现，只支持 test 范围。** 不包含真实业务连接器、多人身份认证或公网服务；服务器部署需另行指定目标。首次安装需要 Python 3.11+ 和获取 PyYAML 6.0.3 的网络。模型登录态不随包分发，界面发送模型上下文仍需明确许可。
