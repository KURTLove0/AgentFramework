# 智能体模型选择与刷新恢复

2026-11-03。源码改进，版本保持 1.3.0，尚未发布。

原来的智能体编辑器在请求开始时记住模型选择，刷新结束后会把等待期间的新选择改回旧值；刷新失败会清空已有选项。重新编辑保存过的配置时，如果模型已经从目录移除，原值也会变成空白。字段修正后，原来的模型错误提示仍可能残留。

现在模型目录返回时使用表单中的最新选择，并保留最后选择的推理强度。刷新失败继续显示已有目录与原选择，用户可以编辑或明确重试；初次读取失败时，已保存或恢复的模型仍会以待核对的原值展示。目录移除了模型或不再支持原推理强度时，保留并标记原值，阻止继续预览配置，要求用户明确选择。修正后清除对应字段错误，摘要也不再把待修正的配置显示为就绪。

切换运行时会清除不属于该运行时的选项。请求序号、编辑会话、空间、租户、身份、运行时及当前控件共同检查响应归属；旧回复不能更新另一份编辑或提前清除新请求的忙碌状态。浏览器模型目录缓存与并发请求按租户、身份分别管理，同一身份的工作空间仍共享目录；旧身份请求完成后不能写入新缓存，也不能清除新请求记录。

这些读取和恢复不会自动保存。最终明确选择仍由已有保存回执流程提交，新任务沿用该智能体版本的冻结配置。
