# 智能体配置打开与读取恢复

2026-11-03。源码改进，版本保持 1.3.0，尚未发布。

原来打开智能体配置需要串行读取若干目录，期间没有明确的加载状态或取消入口。部分读取失败前已重置表单；用户离开页面后，迟到结果仍可能打开编辑窗口。页面缓存过运行时配置后，新建智能体也可能继续使用服务端已经更新的旧默认值。

现在先并行读取运行时配置、智能体或默认定义、领域、职责登记和技能目录，完成并核对归属后再填入编辑器。普通新建和编辑各有七个独立读取；恢复草稿直接使用本地配置，缺少定义的历史配置另行补读默认定义。技能初始化直接使用本次已读取的目录，不再串行重复读取。

等待超过 180ms 会显示读取窗口，说明当前状态并提供取消；快速成功不显示额外窗口。取消或 Escape 立即释放打开入口，不必等原请求结束。读取失败显示原因和“重新读取”，重试沿用原来的新建、编辑、复制或恢复目标。离开原路由或页面隐藏时取消尚未呈现的编辑器；请求、编辑会话、空间、租户与身份变化也会阻止旧结果写入。旧请求的成功、失败或收尾不能覆盖新请求。

新建智能体使用此次读取的运行时默认模型、推理强度与执行参数。编辑、复制和恢复草稿继续采用自身配置，后来更新的默认值不会替换它们。模型目录仍在编辑器打开后读取，等待期间可填写基本信息与工作指令；目录失效选项保留原值并要求明确修正。

2026-11-04 补充：[执行配置切换](agent-template-switching.md)也已按编辑会话隔离。旧模板的迟到响应和收尾不会影响新窗口，等待期间修改职责时保留原配置并要求明确重试。下文保留配置打开这一轮的验收记录。

## 验证

打开编辑器测试从 2 项扩展到 **10 项**，覆盖前置读取并行与延迟应用、当前默认值、原有配置保留、读取失败、取消、旧请求与新请求交错、路由和页面隐藏、空间与身份变化，以及响应身份不匹配。选取三项行为回归对上一轮候选源码执行，三项均失败。相关打开、模型、资源与草稿测试 **197 项通过**；完整前端回归 **1008 项通过**。

**4 组浏览器流程通过**：新增配置打开流程，以及模型选择、智能体草稿和保存恢复。新增流程通过真实页面中的延迟技能目录响应验证 Escape 取消和路由离开；通过合成 503 验证明确重试。随后经 HTTP 更新隔离服务中的运行时默认值，确认页面缓存仍是旧值，再从创建入口打开并保存新配置；第二次更新默认值后重新编辑，确认已有智能体仍保留保存时的模型、强度和超时。没有调用真实模型。

浅深色、1024／1440 像素宽度、正常／28px 提示与按钮文字共 **8 组布局和键盘焦点检查**通过。已检查 [浅色重试界面](agent-opening-light.png) 和 [深色重试界面](agent-opening-dark.png)。初次测试运行暴露了测试桩缺少 `window`、按监听器顺序选取回调，以及测试保存请求包含只读时间字段的问题；更新测试桩和请求后验证通过，没有为这些测试问题修改产品逻辑。

相对上一轮模型选择候选，产品源码变化为 `agents.js`、`skills.js` 和 `index.html`。后端未改，本轮未重复后端全量测试。候选源码包与 wheel 已逐文件校验全部 **166 个程序文件**、内外校验和及内嵌 wheel。日志和源码哈希见 [验收记录](agent-opening-verification-20261103.json)。未发布，未重复全新安装。

取消打开只丢弃浏览器中的结果，不会取消已发送的只读 HTTP 请求；这些请求仍受既有客户端超时约束。并行读取不是服务端跨目录的原子快照，之后仍可能发生配置变更，保存时继续使用现有版本检查与冲突核对。页面隐藏验证属于交互单元测试，本轮没有新增真实浏览器缓存返回测试。
