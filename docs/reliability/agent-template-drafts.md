# 执行配置读取期间保留草稿

2026-11-04。源码改进，版本保持 1.3.0，尚未发布。

执行配置读取较慢时，用户可以继续填写指令与职责，但此前“保留草稿并关闭”也会被禁用。本次允许用户在等待期间保留当前输入，稍后继续编辑。

点击“保留草稿并关闭”后，先将当前表单写入本标签页的恢复副本；成功后释放模板读取的界面使用权、关闭窗口，并将焦点返回“继续编辑智能体”。恢复副本保留原执行配置、当时的职责和指令。恢复后继续输入时，旧请求的成功或失败均不会更改当前表单。

如果浏览器无法存储副本，窗口和输入继续保留，并显示具体提示；恢复存储后可再次点击。失败时不提前释放仍在进行的读取。保存提交、保存结果核对、新领域创建和配置打开仍沿用原有等待保护。模板读取期间也仍不能提交保存。

保留与恢复均不发出保存请求。已发送的只读请求可能继续完成，但成功保留后不会再被界面采用；没有自动取消服务端操作。草稿仍只保留在当前标签页，范围和容量限制见[智能体编辑草稿](agent-drafts.md)。

- 相关测试 30 项、全量前端测试 **1116 项**通过。
- 配置打开、智能体草稿、保存及原提交重试 **4 组真实浏览器流程**通过。新增流程分别延迟成功与 503 响应，验证键盘保留、焦点返回、存储失败、立即恢复、继续输入和迟到结果隔离；两种保留与恢复流程均未发送保存请求。
- 候选包 167 个应用文件与源码一致。相比上一执行配置切换候选包，仅修改 `agents.js` 和 `agent_draft.js`；启动脚本及 6 份历史发行物保持一致。

没有修改服务端、接口或依赖，本轮未重复后端测试或全新安装。浏览器使用隔离合成数据，没有调用真实模型。见[验收记录](agent-template-drafts-verification-20261104.json)。
