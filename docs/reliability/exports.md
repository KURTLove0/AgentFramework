## 使用

任务对话中打开“本轮记录”或“查看本轮执行”，点击“下载本轮记录包”获取 ZIP。历史运行检查页的导出区域也提供“完整记录包 .zip”。每个记录包对应一个实际运行轮次，包含同一读取快照中的结果、事件、证据及上下文清单。

任务属性中的“导出完整对话”继续导出整个任务的消息和回复。Markdown 现包含任务状态、导出时间和每轮实际状态；停止、执行中断、排队及未完成内容有明确标记。已保存报告属于未完成轮次时，同样标明状态，保留正文、限制与说明及原有诊断。引用输出保留来源标识和已保存的引用原文。

运行中的任务可以导出。导出反映读取时的状态，后续执行不会改变这份文件；任务是否完成以导出中的实际状态为准。

## CLI

```bash
# 每次使用新的导出目录，避免覆盖或混入旧文件
python -m agent_framework --data-dir .agent-data export RUN_ID /tmp/task-export-new

# 只读校验目录或浏览器下载的 ZIP，不初始化工作台或调用模型
python -m agent_framework verify-export /tmp/task-export-new
python -m agent_framework verify-export /tmp/RUN_ID-export.zip
```

`demo --export`、`resume --export` 沿用同一导出实现。已有目标目录、文件或符号链接均明确拒绝，已有内容保持原样。命令行会重新读取当前持久状态，不把之前传入的旧内存状态和最新事件拼在一起。

后续改进：独立 `export` 直接只读打开已有运行库，不初始化执行器、不迁移旧数据，也不补建缺失的业务库。相关查询与恢复保护见 [历史任务的只读查询](inspection.md)。

`export` 命令成功生成记录后返回 0，包括被停止或失败的任务；任务自身状态保留在结果和清单中。`verify-export` 的 `valid: true` 表示文件完整性与快照边界校验通过，任务完成情况由 `manifest.snapshot.status` 表达。

## 文件与清单

| 文件 | 内容 |
| --- | --- |
| `result.json` | 冻结任务、实际运行状态、动作、原生读取及停止元数据 |
| `events.jsonl` | 按顺序保存的完整事件序列 |
| `evidence.json` | 同一快照中的证据记录 |
| `context-manifests.json` | 同一快照中的上下文来源清单 |
| `report.md` | 有已保存报告时生成；未完成运行有明确标注 |
| `manifest.json` | 导出格式、应用版本、读取时间、运行版本、事件边界及各文件 SHA-256 和字节数 |

ZIP 和目录使用同一份文件生成逻辑。完整记录包上限为 256 MiB；超过时可使用已有的运行结果和运行记录分项导出。

报告记录文件自身及来源结果的哈希，校验读取保存的内容，不依赖当前版本重新渲染 Markdown。以后调整报告排版时，已有导出仍可校验。

新目录由导出操作独占创建，同步文件、目录项及新建父目录后才撤去 `.export-in-progress` 标记。普通写入异常只清理本次创建且身份仍一致的文件，不递归删除其他进程放入的内容；完整数据进入收尾阶段后，异常不会再删除导出。进程中途退出留下的标记或缺失清单使校验失败，再次导出不会覆盖未完成目录。POSIX 下新导出目录和文件仅允许当前用户访问。

校验检查文件集合、大小、哈希、运行身份与版本、状态、报告对应关系和连续事件边界；拒绝重复 ZIP 条目、额外路径、遗漏文件、篡改或未完成目录。校验过程读取文件，不解压 ZIP、不执行其中内容、不恢复数据库。恢复整个工作台请使用 [核心数据备份与恢复](../data-protection/implementation.md)。

## 读取一致性与范围

运行结果、动作、原生读取、停止请求、事件、证据和上下文共用一个 SQLite 读取事务。WAL 模式下其他进程可以继续提交，导出保持原读取快照，不持有写锁。清单同时记录运行版本及最后事件序号，停止请求等独立控制记录也与事件来自同一快照。

对话导出共用一个读取快照加载消息行、各轮结果与进度及对话版本，避免读取中新增消息后出现“版本已经更新，但消息尚未包含”的情况。普通对话详情也采用这套一致读取方式，导出不依赖本机执行器的内存状态。

Web 下载继续检查租户、工作空间及执行主体。上下文清单仅在运行主体匹配当前用户时提供，历史共享任务保持原有访问范围；CLI 沿用本机运行记录的租户选择。单项 JSON、事件及报告下载保留原接口，新增 `GET /api/runs/{id}/download?kind=bundle` 提供 ZIP。对话导出明确只接受 `json` 和 `markdown` 格式。
