# 原生读取的停止边界

2026-11-02。当前源码改进，版本仍为 1.3.0，尚未发布。

此前停止请求会持久化并通知模型进程，但原生读取代理只检查会话、租约、任务终态与期限。在模型进程退出前，停止已受理的任务仍可能继续读取；正在读取的结果也可能被保存为可信证据并交付模型。三项失败回归分别重现了停止后新建读取、准备过程中停止、读取返回前停止的窗口。

另一组回归发现，停止与读取拒绝、模型超时或资料异常同时发生时，认知错误处理可能先把任务标成失败或等待输入。这样会掩盖用户已经保存的停止意图。

## 当前行为

读取代理在既有范围检查中查询同一事务中的停止记录。这项检查覆盖工具列表、读取预算预留前、准备后的调用边界，以及读取结果成为可信证据之前。只要停止仍待完成，就拒绝继续读取；停止清理失败、等待显式重试也不会重新开放读取。

停止在预算预留前生效时，不创建原生读取记录。已有预留的读取保留 `REJECTED` 记录，并以 `NativeReadCancelled` 标明原因；拒绝结果不会新增证据，也不会返回正文给模型。此前已经验证的证据完整保留。

检查依赖持久化记录，独立代理进程无需等待父进程的内存信号。底层读取在数据库事务外执行，阻塞中的读取不会占住停止请求的写锁。

认知调用出错后，运行时先保留租约失效的处理；若仍持有执行权并发现停止意图，则沿用既有取消流程。普通任务结束为已停止，业务工作流先核对已经发出的写入，无法确认的结果仍交人工处理。没有停止请求时，原来的失败、等待输入等状态规则继续生效。

## 验证

新增 13 项专项测试覆盖三个读取窗口、停止清理失败、其他任务范围、已验证证据保留、独立代理进程、并发阻塞读取，以及直接任务、对话与工作流的错误竞争、无停止时的状态、已有写入核对和租约替换。61 项首轮相关回归通过，扩展后的 13 项专项测试也全部通过。

浏览器在读取开始前和读取过程中分别暂停固定模型替身，排队下一条消息、停止当前轮次、保留未发送草稿并刷新，随后释放测试暂停点。前一条路径没有调用适配器，后一条路径调用一次但结果被拒绝；两者都没有交付工具结果或保存该读取的证据。页面保留原始片段并标明未完成，停止结果为 `CANCELLED`，明确排队的下一轮各执行一次。

测试夹具分别修正了模块导入依赖、对话任务缺失冻结上下文，以及浏览器对未完成片段字段的错误假设。这些修正没有改动产品协议或降低断言；最终检查现有 `preview` 和空 `reply` 字段。

## 边界

停止检查发生在既有执行边界，不能撤销此前已发出的读取，也不能收回停止前已经提交并交付的结果。在途底层读取可能继续到返回或超时；本次保证的是检测到停止后拒绝继续执行或保存、交付未提交的读取结果。外部读取与数据库停止提交之间不构成分布式原子操作。

该改动约束受控原生 READ 工具，不新增写入能力或补偿操作。普通任务的模型进程退出仍由既有停止机制负责。测试使用隔离临时资料、真实读取代理与固定模型替身，没有使用生产数据，也不验证真实模型理解质量。

候选包未发布，本轮不重复全新环境安装验收。最终测试结果、源码摘要和包校验信息见 [验收记录](native-read-cancellation-verification-20261102.json)。

最终通过 1115 项后端测试、787 项前端测试，以及原生读取停止、持久化取消、模型上下文刷新和未引用资料来源四组浏览器验收。候选包的 143 个程序文件与当前源码一致，包内 wheel 与单独 wheel 相同，内外校验清单通过。
