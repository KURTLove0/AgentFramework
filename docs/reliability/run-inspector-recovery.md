# 本轮运行记录的读取与恢复

2026-11-01，源码增量。完善任务对话中“本轮记录”和“查看完整运行记录”的窗口。发布版本仍为 1.3.0，未重新构建安装包。

## 查看记录

点击后立即打开当前轮次的记录窗口，显示该轮消息与读取状态；慢读取期间可直接关闭。读取成功后展示运行过程、完整事件及来源检查，并标明状态与读取时间。

首次读取失败在原窗口显示原因和“重试读取”。已有内容后的刷新失败，会明确说明仍显示上次成功读取的记录，保留原读取时间。错误不会被伪装成空事件或最新状态。重新读取成功后更新内容；展开的证据区域、滚动位置和可用的按钮焦点尽量保留。

服务返回无访问权限或记录不存在时，移除保留的旧内容和下载入口。窗口始终可以关闭，不要求用户为了退出而反复重试。

## 请求与下载范围

每次打开绑定当前租户、操作人、工作空间、任务、路由及目标轮次。只读取当前对话已有的运行；返回的运行 ID 必须与请求一致，才能展示内容和提供下载。

同一窗口正在读取时，重复点击不会启动第二次读取。新的轮次窗口取代旧窗口后，旧结果和旧错误都不能再更新它。关闭窗口、切换路由或离开页面会使原请求失效；浏览器返回缓存也不会恢复未关闭的旧记录窗口。

“下载本轮记录包”绑定打开时的运行与工作空间，不从回调结束时的可变页面状态拼接地址。下载继续使用既有导出接口和服务端访问校验。读取时间表示页面获得这份详情的时间；下载包采用下载时的服务端一致快照，运行中的任务可能已经产生新的记录。

本轮仅增加页面读取与恢复行为，没有新增业务写入、授权或执行动作，也不改变既有记录包格式。完整导出规则见 [任务导出与完整记录包](exports.md)。
