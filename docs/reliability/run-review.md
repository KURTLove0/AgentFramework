# 人工核对信息与工具记录

2026-11-03。当前源码改进，版本仍为 1.3.0，尚未发布。

此前“按幂等键人工核对”的提示没有同时展示核对标识。完整动作参数在历史详情的工具页内，但对话中的运行记录窗口仅展示事件、证据与检查，缺少完整工具动作。核对者需要在不同入口间寻找对应操作。初始新增的 3 项回归全部失败。

## 当前行为

待人工核对的运行在运行过程上方显示核对信息，包含运行编号、记录版本、租户、项目和执行身份。未决操作显示工具、操作编号、状态、项目、已保存的幂等键；已有回执的操作还显示回执对象和版本。信息来自当前显示的运行快照，不猜测业务结果。

`DISPATCHED`、`UNKNOWN`、`RECONCILING`、`NEEDS_REVIEW` 与 `OBSERVED` 分别说明派发、未知、核对中、人工核对和已有回执但尚待核验。面板同时列出未通过的检查及已保存依据，尚无检查结论时显示“尚未检查”，不将其标记为失败。没有待核对动作的只读结果仅给出原因与检查指引，不虚构外部写入。

“复制核对摘要”复制这份记录的标识、状态、操作和检查信息，不复制完整动作参数或报告正文。摘要全文可展开并手动选择；剪贴板不可用时会显示提示并打开全文。复制过程中切换焦点或关闭窗口，迟到的结果不会重新打开窗口或抢走其他控件的焦点。

对话的运行记录窗口新增“工具操作记录”，可展开查看原始动作参数、回执及授权等已保存内容。刷新失败时继续明确展示上次记录；访问失效时清除旧摘要、动作与下载入口。原记录包下载仍可用于完整审阅。

## 验证

新增 8 项摘要与复制回归，以及 1 项运行窗口完整动作回归。34 项相关前端回归、全量 809 项前端回归通过；运行详情、导出与交付相关的 56 项后端测试通过。本轮未改动后端生产逻辑，未重复全量后端测试。

浏览器通过真实模拟执行产生三项待核对任务：回读失败的多轮对话、回执存在但草稿内容不一致的任务，以及回读失败的单轮历史详情。核对面板与原始动作逐字段一致；查看、复制和刷新前后的运行、动作、事件、证据、业务调用及草稿一致，未发起 POST。多轮对话的排队消息仍保持等待。

剪贴板使用隔离浏览器替身，验证成功和拒绝分支，不写入系统剪贴板。12 种深浅色、1440 / 1024 / 375 像素宽度、正常与两倍面板文字组合下，复制按钮可聚焦且完整可见，无页面或对话框横向溢出。已目视核对深浅色面板截图。另三组现有浏览器验收——运行记录窗口、待核对对话队列、模型失败提示——通过。

首次新浏览器验收使用卡片全文匹配工具名称，误命中了原始读取记录中对写入能力的引用；改为按工具标题精确定位后通过。产品代码无需为此修改。

## 范围

本轮沿用 `ui-ux-pro-max` 的错误恢复与反馈指导，使用已有主题和记录窗口。核对面板是只读信息入口，不提供人工裁决、重新执行、强制确认成功或解除未决动作的操作；已保存的运行状态与审计事实保持原样。
