# CLI 检测的状态隔离与恢复

2026-11-03。源码改进，版本保持 1.3.0，尚未发布。

原来的 CLI 检测按钮由单个请求直接启用或禁用。切换运行时后，旧请求失败可能覆盖当前提示；检测与配置保存同时进行时，先完成的检测会提前启用按钮，或者保存结束后仍保留过期的禁用状态。离开再返回也缺少检测结果的归属检查。

现在检测状态属于本次配置编辑，并按 Codex、Cursor、Qoder 或模拟运行时分别记录。等待期间显示具体运行时和忙碌状态，同一运行时的重复请求会被忽略；切换到其他运行时可独立检测，切回可查看原结果。配置保存与检测的等待状态共同决定按钮是否可用。离开页面、恢复缓存页面、切换空间或身份后，旧检测结果不能修改新编辑器；恢复页面不会自动启动检测。返回的运行时或响应字段不匹配时显示可重试错误。

后端继续只执行固定 CLI 的 `--version`，不提交模型提示、不保存配置。版本探测改用非阻塞管道，关闭标准输入，设置 5 秒读取期限与 64 KiB 累计解码输出上限。标准错误也受限，但不展示其内容；成功只展示标准输出的首行，最多 160 字符。失败输出、内部异常路径不会直接显示在界面。

成功、超时、异常和初始化失败都会清理所属进程组并关闭本地管道，包括主进程退出后仍占用输出管道的子进程。无法确认清理时显示失败并提示检查残留进程；同时存在超时时保留超时原因。读取期限之后的进程清理有额外等待，因此 5 秒不代表严格的 HTTP 总耗时上限。

## 验证

新增 **8 项前端交互测试**，改动前 7 项失败，改动后全部通过。覆盖运行时切换、重复请求、两种完成顺序、旧编辑器回调、错误响应、空间与身份变化、隐藏页面以及保存期间禁止启动检测。

新增 **12 项后端测试**使用真正的临时 Python 进程覆盖固定参数与输入关闭、静默和持续输出超时、输出关闭但进程仍运行、标准输出与错误输出共同受限、无效与拆分 Unicode、失败后重试、残留子进程、启动失败、管道初始化失败、清理权限异常以及调用方正在处理的无关异常。测试结束检查进程和管道，没有新增读取线程。

完整回归通过 **1383 项后端测试、989 项前端测试**。**4 组浏览器流程通过**：新增 CLI 检测流程，以及配置页生命周期、配置保存与恢复、模型目录故障恢复。新增流程通过临时 Python CLI 真实触发版本检测超时，配合延迟 HTTP 响应验证切换、保存和返回的交错状态；页面生命周期交错案例使用受控事件，独立生命周期回归另有真实缓存返回验证。全部使用离线数据，未调用真实模型。

浅深色、1024／1440 像素宽度、正常／28px 检测提示字号共 8 组布局与焦点检查通过。已检查 [浅色超时界面](runtime-detection-light.png) 与 [深色超时界面](runtime-detection-dark.png)。候选包逐文件校验和日志哈希见 [验收记录](runtime-detection-verification-20261103.json)。本轮未发布，未重复全新安装。

检测结果只表示该次本机 CLI 版本命令的结果，不证明登录态或模型权限可用。结果仅保留在当前编辑器内；离开页面不会请求服务端取消已开始的检测，检测仍受自身期限和清理流程约束。
