# 运行时配置的修改核对与保存反馈

2026-11-03。源码改进，版本保持 1.3.0，尚未发布。

配置页面原先会保留最近一次读取或保存的提示，继续编辑后仍可能显示“保存已确认”。现在按当前状态展示反馈：普通编辑显示未保存修改数量；存在未决保存或版本冲突时，优先保留核对提示；保存成功后说明新建智能体可使用新配置，现有智能体与任务保持原配置。

“查看未保存修改”可展开逐项比较，包括默认运行时，以及 Codex、Cursor、Qoder 的模型、超时、修复上限和推理强度。表格明确标出编辑基准版本与本页原始输入，未填完的字段显示“尚未填写”。它只比较本页内容，不发送保存请求。模型选择联动改变推理强度时，两项变化一并展示。

编辑与异步核对保留差异区、原提交和当前配置区的展开状态。明确选择“保留输入，按当前版本继续”后，差异表使用新基准；回执核对确认原提交后，只显示后续仍未保存的变化。全部还原为编辑基准时，清理当前标签页草稿，并提示没有未保存修改；清理失败仍保留现有存储错误提示。

比较使用原始输入，因此 `60` 与 `060` 等输入形式也会列为修改；最终参数规范化和版本冲突检查继续由保存接口负责。编辑基准是页面已读取并确认的版本，不代表服务器此刻没有其他更新。

## 验证

改动前，4 个新增交互用例复现读取或保存提示滞留、缺少逐项比较、全部还原后仍保存草稿，以及恢复状态无法展示后续差异。改动后完整前端回归通过 **975 项测试**。

**4 组浏览器流程**通过：新增修改核对流程，以及运行时配置恢复、模型目录故障恢复、智能体草稿回归。新流程覆盖多运行时编辑、键盘展开、编辑焦点、模型与推理强度联动、冲突后更换基准、清除已还原草稿、保存后继续编辑，以及回执丢失后保留新输入。浅深色、1024／1440 像素宽度、正常／28px 字号共 8 组布局检查通过。
