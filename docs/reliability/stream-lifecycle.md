# 实时连接的容量、后台释放与重连

2026-11-02。当前源码改进，版本仍为 1.3.0，尚未发布。

此前每个任务页面都能持续打开 SSE，后台标签页也不释放连接。断线之后依赖浏览器默认重试；标签页越多，长连接和重复详情读取越多，普通请求也可能等待可用连接。

## 当前行为

同一服务实例默认最多保留 4 条同时打开的任务推送连接，各工作空间共用名额。容量已满时立即返回 HTTP 503 和 `stream_capacity_full`，不排队，也不读取整份对话历史；任务详情、轮询和停止操作继续使用普通请求。

连接名额覆盖初始读取和整个推送过程，读取失败、断线、任务结束、连接到期或服务关闭时均会释放。空闲连接通过非阻塞的可读性检查识别对端关闭，不必等到下一次心跳才回收。单条连接仍按原策略约 60 秒轮换；已经开始推送后发生意外错误，会结束当前流，不再把第二份 HTTP 错误响应拼入事件正文。

页面进入后台或离开时关闭推送并撤销重试计时器。返回页面时立即做只读刷新，再按原任务的重试状态恢复推送。页面缓存恢复也会重新接通；已有回答、未发送草稿和任务身份继续沿用原状态，不自动发送消息。

连接出错时，页面主动关闭浏览器的默认重连，改用 1、2、4、8、16、30 秒的递增等待，附加最多 500 毫秒的小幅随机延迟。等待时间使用单调时钟，系统时间调整不会延长或跳过等待。只有收到并接受有效任务快照才重置失败次数，重复渲染、连接打开或格式错误的数据都不能绕过等待。更换任务、工作空间或身份会撤销旧计时器，迟到的旧连接回调不能重开或关闭当前连接。

## 验证

新增 9 项后端回归使用真实本地 HTTP 连接，覆盖并发抢占、跨工作空间容量共享、暂满期间的普通读取与停止、初始读取失败、推送中异常、空闲断开、任务结束、连接期限及服务关闭。

新增 11 项前端回归覆盖递增等待及重置、错误快照、时钟调整、后台与前台切换、页面缓存恢复、任务与身份切换、等待期间任务结束，以及迟到事件。

浏览器验收使用七个同源标签页和一个隔离的合成模型任务，确认最多四条实时连接。未获名额的标签页仍通过轮询看到新进展，保留草稿和光标。真实服务端主动断开连接并连续返回 503 后，浏览器按递增间隔重试；恢复后接回原任务。四条推送同时打开时执行停止，最终只创建一次任务、调用一次模型、发送一次停止请求，没有发送补充消息。

Headless Chrome 在本环境中把所有标签页都报告为可见，因此后台场景通过受控的 `document.hidden` 与 `visibilitychange` 驱动真实页面处理器；HTTP、SSE 连接及服务端释放均为实际行为。页面缓存恢复另由前端事件回归覆盖，不将其描述为操作系统后台切换的实测结果。

最终命令、结果、浏览器观测和源码摘要见 [验收记录](stream-lifecycle-verification-20261102.json)。

最终通过 1030 项后端测试、787 项前端测试，以及连接生命周期、实时对话和停止操作三组浏览器验收。候选包的 139 个程序文件与当前源码摘要一致，包内及单独 wheel 相同，内外校验清单通过；本轮未重新进行全新环境安装验收。

## 边界

- 名额限制属于当前应用服务实例，不跨独立进程协调，也不限制所有普通 HTTP 请求线程。
- 这限制的是同时存在的长连接，不承诺总内存或所有请求的固定延迟。浏览器后台调度、操作系统休眠与网络恢复仍可能推迟实际回调。
- 客户端没有 EventSource 时继续使用现有轮询。推送暂满不意味着任务执行失败，也不接受新的任务写入。
- 测试故障入口只存在于隔离验收脚本，未加入产品接口；未改变数据库格式或版本号，未调用真实模型、发布或部署。
