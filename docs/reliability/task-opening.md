# 任务准备与读取重试

2026-11-04，当前源码改进，版本仍为 1.3.0，尚未发布。

点击“新建任务”后，需要读取可用智能体、运行时和已保存的任务设置。此前慢读取只有入口按钮停用，失败原因显示在短暂提示中，用户难以判断是否已经开始执行。

现在读取超过 500 毫秒会显示“正在准备任务”，说明尚未开始执行；快速读取直接打开表单。等待期间可点击“取消”或按 Escape。取消后恢复入口的键盘焦点，入口因页面重绘消失时回到内容区。失败原因持续显示在窗口中，可选择“重新读取”或取消。错误内容按普通文字展示。

重新读取沿用原入口：从指定智能体发起时保留选择，基于已有任务新建时保留来源与初始目标，从配置页返回时保留已输入目标和原智能体选择。读取会再次取得当前配置；原智能体已经不可用时，仍须重新选择。已有独立草稿和待核对提交继续按原有规则处理。

准备只读取配置，不启动任务。取消会立即释放本页等待状态；已经发出的只读请求可以结束，但结果不再应用。页面离开、身份或空间变化后，旧结果不能重开表单，旧请求收尾也不能关闭后来打开的窗口。新任务仍须明确点击“开始任务”才提交。

准备期间打开其他对话框（例如转去创建智能体）也会立即取消原准备。随后即使关闭新窗口，旧配置读取也不会重新弹出任务表单。读取完成时还会检查当前窗口，避免与对话框打开通知的时序交错。准备成功或取消时移除临时监听。

首轮新增 7 项交互测试，覆盖快慢读取、取消、重试来源、旧响应、页面离开和配置返回。在改动前的真实源码上有 5 项失败、2 项通过；首轮全部 1150 项前端测试通过。

后续衔接检查在真实浏览器复现了“打开智能体编辑器后，任务表单被旧请求弹出”的问题。补充 3 项交互测试验证新窗口接替、通知时序与旧错误窗口清理；原实现 7 项通过、3 项失败，修复后 10 项均通过，全部前端测试共 1153 项通过。浏览器进一步验证先关闭新编辑器、再返回旧读取仍不弹窗，并回归任务复用和智能体打开流程。

浏览器从干净工作台创建首个智能体，模拟慢读取和失败，验证取消、键盘重试、配置返回及一次完整任务执行；另回归任务复用与独立草稿流程。三组流程通过。准备窗口在浅色／深色、1024／1440 像素、正常／28px 字号共八组桌面布局下检查焦点和边界，并目视核对截图。测试使用临时数据和合成运行时，未调用真实模型。
