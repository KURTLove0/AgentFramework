# 基于已有任务新建

2026-11-04 补充：[任务准备窗口](task-opening.md)为慢读取增加取消入口，读取失败可在窗口中重试，并继续使用原任务来源和初始目标。

2026-11-03。源码改进，版本保持 1.3.0，尚未发布。

旧运行详情已有“基于此任务新建”，但主要使用的多轮任务对话没有这个入口。现在可以从任务信息直接复用初始目标，核对当前智能体配置后创建独立任务，避免手动复制目标，也避免把新建误认为继续原对话。

## 使用

打开任务的“任务信息”，点击“基于此任务新建”。新建窗口带入初始目标，可继续修改；默认选择原智能体的当前可用版本，并展示“原任务 vX → 新任务 vY”。选择其他智能体后，说明随之更新。原智能体已归档或不存在时保留目标，要求重新选择。

此入口带入初始目标，不复制后续要求、回复或原执行结果。点击“开始任务”后才创建独立编号，使用所选智能体的当前配置并重新检查版本。新任务的对话历史从空开始，原任务的结果、审计、权限和各轮消息保持不变；具体业务写入仍由原有授权流程处理。新任务的任务信息提供来源链接，可返回原任务。与失败轮次在原对话中“重试”是两条不同的动线。

当前简洁新建表单仍只提交目标和所选智能体等原有字段；执行预算、模型及工具配置遵循现有新建逻辑。旧式运行详情的高级复制流程继续保留其原有业务输入与预算规则，不把旧写入授权或故障注入场景带进新任务。

## 草稿与待核对提交

如果已有另一份保存的任务设置，新建窗口会说明它仍被保留。可以展开查看旧目标和智能体，然后选择：

- 直接开始本页的新任务：保留已有设置草稿，不自动替换或清理。
- “使用已保存设置”：恢复原草稿，撤下本次未采用的来源说明。
- “用本页设置替换草稿”：明确保存本页内容，沿用草稿版本检查；其他页面再次修改时仍会拒绝覆盖。

复用时存在旧草稿，会暂停本页自动保存，直到用户明确处理。保存复用设置后，刷新可通过“继续上次任务设置”恢复目标、智能体与来源编号。草稿只保存来源编号，不保存或伪造原配置版本；恢复后的说明明确提示原版本可在来源任务查看。

如果有从配置页面返回的未完成设置，先打开这些设置并说明本次复用尚未进行；不会悄悄改成另一个任务。如果上次提交结果尚未核对，则先恢复原提交及原请求编号，沿用既有只读核对和重试机制。新建窗口已打开时重复调用入口会聚焦已有输入，保留当前编辑。

对话输入框的草稿与新建设置继续分开。取消未修改的复用窗口不创建任务；编辑后的取消沿用现有保留、放弃和保存冲突处理。

## 准备配置时的页面保护

新建与从配置页面返回都会并行读取当前配置，并固定请求所属工作空间。页面、任务、租户或主体已经变化时，迟到的成功或错误不再修改当前表单、配置目录或提示。路由变化使旧准备操作失效，新页面可以开始自己的准备；旧请求完成也不能清除新请求的等待状态。

读取完成并确认仍属于当前页面后才重置和填入表单。准备失败保留原表单内容、释放按钮并显示原因，用户可明确重试。重复点击不会并发创建多个准备过程。这里阻止的是旧结果被采用，已经发出的只读请求仍可能在服务端完成。

## 验证

新增 7 项后端测试核对新任务编号、当前配置、空历史、独立权限、原任务不变、旧草稿保留、提交幂等、过期配置、归档智能体、来源权限及离线静态资源。新增 15 项前端测试覆盖复用说明、配置切换、草稿选择、待核对提交、重复操作、页面与身份变化、迟到准备、失败重试和配置返回。

浏览器使用隔离的离线任务，真实完成两轮原对话，修改智能体后复用，再检查新任务与原任务的持久记录。流程覆盖取消、独立草稿、来源返回、归档后的重新选择、保存与刷新、迟到配置和 503 重试。布局覆盖浅色／深色、1024／1440 像素宽度、正常／28px 字号，检查键盘焦点、底部操作区和横向溢出。已检查 [浅色复用窗口](task-reuse-light.png) 与 [深色复用窗口](task-reuse-dark.png)。
