# 跨任务消息正文搜索

2026-11-03。源码改进，版本保持 1.3.0，尚未发布。

任务列表和全局搜索此前只匹配任务名称、初始目标、编号等摘要。隔离样本中，搜索已保存的第三轮要求或回复正文均得到 0 条结果。现在搜索可通过后续要求和已保存的回复找回对应任务，即使标题中没有关键词。

## 查找与定位

任务列表和全局搜索继续使用原搜索框。每个任务只列一次；仅正文命中时，显示最早命中的轮次、消息类型和一小段原文。任务名称仍可打开任务，片段按钮直接定位命中消息。全局搜索选中正文结果也会直接定位。

正文匹配参与分页前的筛选，超过一页仍能找到完整结果。默认列表不含归档；“只看收藏”、状态、智能体、领域及日期条件仍然有效。全局搜索包含归档，选择“查看全部”会清除原列表的收藏等限制，避免漏掉已显示的全局匹配。

点击命中片段后打开指定轮次，并沿用对话内查找高亮可见正文；若消息已经修改或关键词只出现在 Markdown 源文本中，仍定位原轮次并说明当前可见正文未找到原关键词。不会更改消息或发送输入框草稿。后台刷新不重复滚动或抢回焦点。

轮次链接形如 `#/runs/{task}/turn/3/assistant`。刷新或再次打开可恢复该轮次位置；关键词只保留在当前页面内存，不写进链接。返回列表沿用既有浏览器历史恢复搜索条件和页码。切换空间、身份或任务后，旧查询不会用于另一会话。

## 搜索范围与读取

关键词最多 200 个字符，去除两端空白后按忽略大小写的字面子串检索，不把 `[]`、`+`、`%`、`_` 当作正则或通配符。返回的片段保留原字符、大小写与换行；列表合并显示空白并自然换行，让命中文字直接可见。浏览器以纯文本显示并高亮，不执行其中的 HTML；完整原文可打开消息查看。

正文包括当前保存的用户消息（含排队和取消的消息），以及回复的 `content`、`answer` 或结构化报告各节正文。排队消息修改后直接搜索新文字，无异步索引延迟；旧修改版本仍在修改记录中，不混入当前正文搜索。尚未形成回复的生成片段、过程日志、工具参数、引用详情和配置不在跨任务正文范围内；已打开对话中的生成片段仍可使用原有“查找对话”。工作台的最近任务筛选仍限于摘要，完整正文搜索请进入任务列表或全局搜索。

`GET /api/runs?search=...` 保持原分页及筛选参数；仅正文命中的条目增加 `search_match`，包含轮次、运行编号、角色及 `before` / `match` / `after` 三段原文。每侧上下文最多 64 个原字符，必要时增加省略号。标题等摘要已命中的任务沿用原展示，无需返回正文片段。

正文扫描仅接收已通过目录权限与归档、收藏范围的根任务，继续检查会话工作空间、主体及回复运行的项目与主体。读取分批执行于同一 SQLite 快照；返回每个任务最早的一条匹配，不载入执行事件、工具动作或完整会话详情。没有新增数据库表、写入、后台索引或模型调用。旧记录缺少标准回复结构时跳过不可读正文，仍可搜索任务摘要和用户消息。

## 验证与边界

新增 13 项后端测试覆盖后续消息和回复、完整分页、原摘要兼容、回复结构、Unicode 和字面字符、当前修改、取消消息、收藏归档、权限、只读旧数据库、批次快照、异常旧报告及 HTTP。新增 13 项前端测试覆盖片段转义、深链接、指定轮次与角色、刷新、迟到导航、身份变化、缺失轮次、正文变化及全局搜索跳转；原全局“查看全部”测试补充收藏筛选重置断言。

合成测量使用 80 个任务、320 轮，每轮回复及审计事件各填充 32768 字节。四种查询耗时约 0.08–0.14 秒；50 条回复命中返回约 57 KB。此为本机单次观测，不代表生产容量保证。正文按需扫描，尚未承诺大规模全文索引或语义搜索；搜索的是保存的源文本，Markdown 跨格式标签的可见短语不一定能作为连续字串命中。

浏览器使用 105 个合成任务验证三页结果、键盘定位、高亮、刷新与返回、草稿保留、收藏归档、全局转入完整列表、排队编辑后的新旧查询、符号与 HTML 文字、迟到请求及工作空间隔离。视觉检查覆盖深浅色、1024 / 1440 像素和正常 / 28px 字号。所有数据与服务均为临时测试夹具，无真实模型或业务系统调用。

完整回归通过 **1281 项后端测试、914 项前端测试及 4 组浏览器流程**。截图检查发现并修复了多行前文把关键词藏在片段滚动区中的问题，最终布局直接展示命中文字。已检查 [浅色搜索结果](task-text-search-light.png) 与 [深色搜索结果](task-text-search-dark.png)，性能原始观测见 [合成测量](task-text-search-measurement.json)。最终日志、源码和候选包校验见 [验收记录](task-text-search-verification-20261103.json)。本次未发布，也未重复全新环境安装。
