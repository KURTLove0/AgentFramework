# 工作流提案授权与核对

2026-10-31，源码增量。工作流授权从仅指定节点，改为绑定用户审查的具体提案；补上未知响应的核对入口。本轮未重新构建安装包，发布版本仍为 1.3.0。

## 用户可见的变化

“授权此提案并继续”提交页面当前显示的提案标记。等待期间若提案内容、动作身份、节点任务轮次或授权状态变化，服务端拒绝旧请求，不自动采用另一份内容。错误说明保留在提案旁，提供“核对当前提案与运行”。

核对只读取运行详情，不提交授权。读到新的待授权提案后，用户重新审查并明确点击才会授权；若原请求已经接受，页面显示“授权已保存”和实际排队状态。核对失败保留当前显示与重试入口，不把保留内容称为最新结果。

提交期间，同一节点的重复点击与重绘后的按钮均不能再发送授权。结果不明确时先核对，阻止直接重复点击授权。旧页面、旧空间或旧身份的回调不能覆盖当前详情；晚到的旧响应不能撤销较新的取消状态。离开期间完成的核对不会把按钮永久留在处理中，返回后可再次核对。

## 服务端接受规则

运行详情为每个具体待写入提案返回 `children[node_id].proposal_token`。该标记绑定租户、空间、主体、工作流、节点、当前子任务、冻结快照、动作身份、工具、参数、参数摘要、资源范围及当前授权状态。它用于核对审查内容，不能替代已有身份、空间访问或 CSRF 校验。

接受授权时，在同一数据库写事务中重新读取工作流、当前节点任务、提案和已有授权，检查取消状态、任务状态及参数摘要。详情与授权使用同一套最新对话轮次解析；不会展示后续轮次却给初始任务授权。

校验通过后，授权、派发登记和 `workflow.granted` 回执共同提交。失败全部回滚，不能出现有权限但未登记派发或未留下回执的半份结果。回执保存在现有 `workflow_events` 中，没有新增数据库表。

已接受的同一提案标记再次提交时复用原回执：不再写入授权、延长有效期或增加派发代次。服务重启后仍有效；后来撤销、过期或取消不会因旧请求重放被逆转。仍有效的同参数授权也直接复用。若需要对已撤销或已过期的提案重新授权，需读取当前状态并提交新的审查标记。

重放返回的运行详情可能已是取消或终态；“原授权曾被接受”不表示它现在仍有效，也不表示业务写入已完成。HTTP 处理仍可能尝试推进已经存在的持久执行请求，但重放不会登记新的执行请求或改写取消原因。

## 接口变化

`POST /api/workflow-runs/{id}/grant` 现在要求：

```json
{
  "node_id": "review",
  "proposal_token": "详情中对应提案的 64 位标记"
}
```

客户端应使用刚刚展示给用户的详情标记，不应在提交时自动读取并替换为新标记。缺失、格式错误或额外字段返回 400；提案或可授权状态不符返回 409。既有界面、模拟演示和测试调用方均已更新。旧页面需要刷新后再审查授权，不保留仅提交节点的宽松入口。

读取和核对沿用 `GET /api/workflow-runs/{id}`。标记及回执不自动授权任务的新一轮，也不取消任何已在途的业务操作。普通单任务的独立授权入口不在本轮修改范围内。

## 验证

- 完整前端回归 **543 项通过**，新增 **14 项**交互测试，覆盖冻结请求体、重复提交、未知结果、只读核对、路由与身份隔离、过期回调和取消状态保持。
- 相关后端、对话与 HTTP 回归 **111 项通过**，新增 **19 项**提案授权测试，覆盖内容或动作变化、事务内重查、最新对话轮次、四个并发提交、回执重启恢复、撤销、过期、取消、错误格式和回滚。
- **5 组浏览器套件通过**：`workflow-grants`、`workflow-sync`、`workflow-queue`、`workflow-agents`、`workflow-starts`。
- 新浏览器套件实际拦截授权请求，在到达服务前替换合成提案，验证旧请求被拒绝且未派发；明确读取新提案后才再次提交。另模拟授权已经保存但响应丢失，核对时没有第二次提交，重放已接受回执也不增加事件或覆盖取消。
- 浅色/深色、1024/1440 宽度、100%/200% 文字共 **8 组桌面布局**通过。错误说明与核对按钮可到达，键盘可聚焦，无横向溢出；最终截图已人工检查。

测试使用一次性本地服务和合成数据，不调用外部模型。早期浏览器验证中的隐藏审计内容定位已改为具体提案区域；旧同步套件现在等待完整目录及历史读取后再查看最新记录，保持原有取消优先断言。

## 当前边界

页面上的错误与核对状态保留在当前页面内存，刷新后重新读取服务状态；未新增跨设备的待授权草稿。授权事实与已接受回执在服务端持久保存。本地浏览器关闭不撤销既有授权，取消仍使用原运行的取消入口。业务工具仍为模拟实现，本轮未发布安装包。
