# 当前支持范围：桌面 Web 与 PC

用户要求仅实现 Web 端和 PC 端，手机端不属于当前产品实现范围。这里的 Web/PC 指现有项目在桌面浏览器及本地 PC 工作台中的使用；本次不引入新的原生应用技术栈。

## 开发与验收

- 桌面窗口：1024、1280、1440、1920 CSS px，分别验证浅色与深色。
- 交互：鼠标、键盘、中文输入、焦点恢复、表单错误、筛选与分页。
- 阅读与尺寸：标题 28px、正文和输入 14px、重要辅助文字 13px；同栏控件 40px，圆角 8px，默认边界至少 3:1。
- 浏览器文字缩放：在 1024、1440px 验证 200% 文字，保持内容、输入框和弹窗操作可达。
- 十二个入口、十类编辑器、长名称目录和详情，共 192 个普通场景；三个目录与四类编辑器，共 14 个放大文字场景。

运行 `npm run test:desktop`，或在已安装依赖的项目虚拟环境中运行：

```sh
.venv/bin/python scripts/run_browser_tests.py --suite ui-details
```

已有窄屏兼容样式与历史回归记录保留在代码库中；它们不构成独立手机版本的开发计划。今后的 UI 评分维度为字号、控件、展示框、交互状态和桌面窗口适配。历史 96 分报告保留当时口径，本次不因平台范围变化直接加分。

## 本次验证

桌面验收已通过：192 个正常场景、14 个 200% 文字场景；四种桌面宽度、深浅主题，未发现本轮检查项中的溢出、遮挡、字号、控件尺寸或边界对比问题。结果保存在 `/private/tmp/af-desktop-scope-20261028/ui-details/results.json`。
