# 字体与展示框细节复评

本轮沿用上次 80/100 的五个维度与权重。评分标准在修改前固定，不因测试通过直接提高视觉分，也不改变既有配色、业务流程或授权边界。

最终结果见 [96/100 复评报告](FINAL_REVIEW.md) 和 [量化证据](evidence.json)。

## 固定标准

每项 0–5 分：5 = 已验证且一致；4 = 只有非阻断的局部细节；3 = 有明显不一致；2 = 影响阅读或空间利用；1 = 严重问题；0 = 缺失。未验证的项目不计为通过。存在遮挡、不可操作、数据丢失或页面溢出时，不得宣布达到目标。

| 维度 | 满分 | 检查项（每项 5 分） |
| --- | ---: | --- |
| 字号与层级 | 25 | 同级页面标题统一；手机正文 16px；手机标签与重要说明至少 14px；行高与长文可读；长名称和 200% 文字可达 |
| 输入框与选择框 | 25 | 同栏高度误差不超过 1px；圆角与内边距统一；正常边界对输入面至少 3:1；聚焦/错误/禁用不改变布局；下拉层级与选项清楚 |
| 展示框与空间 | 25 | 短枚举在桌面限定合理宽度；空态按内容收缩；卡片/弹层层级明确；页头与工具栏节奏一致；有数据和长内容布局合理 |
| 交互状态 | 15 | 键盘/输入法/焦点恢复；错误校验与保存反馈；既有主要操作回归 |
| 手机适配 | 10 | 五种宽度及触摸设备无横向溢出与遮挡；200% 文字和触控区域可用 |

基线依据：上一轮只读评审记录 `/private/tmp/af-ui-detail-rating/measurements.json`。已确认的问题包括 12–13px 手机说明、同栏 40/42/44px 高度、知识库状态框 518px、运行空态 312px，以及约 1.9–2.1:1 的默认输入边界。

## 验证范围

复评覆盖全部十二个入口、常用编辑弹窗、含记录的列表与任务详情；浅色与深色；320、375、414、768、1440px；触摸指针和 200% 文字。自动测量用于字号、尺寸、对比、遮挡和溢出；截图人工检查用于层级、留白与密度。最终分数和未满分原因记录在本目录的最终评审中。
